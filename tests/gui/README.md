# GUI tests

Shared GUI and viewer tests belong here after the common application shell is
introduced. GUI tests must remain separable from headless numerical tests.

Until Phase 6, the pinned GUI-visible legacy behavior and known product
differences are inventoried in `docs/phase1/BEHAVIORAL_INVENTORY.md` and
`docs/phase1/LEGACY_DIFFERENCES.md`. Platform-dependent screenshots are not Phase
1 goldens.
