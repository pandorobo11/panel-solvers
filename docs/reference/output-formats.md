# Output format reference

This page is the canonical inventory for the documented Summary CSV and VTP
semantics. Serialization bytes, temporary filenames, and metadata ordering
inside VTP are not contracts.

## Summary CSV

The writer emits canonical input columns, then accepted non-reserved unknown
input columns in their source order, then the product's result columns. The
retired `save_npz_on` field is not an accepted unknown column: case readers
reject it and old case files must remove it. Summary CSV also no longer contains
the retired `npz_path` result column.

FMF result columns, in order:

```text
solver_version, case_signature, run_started_at_utc, run_finished_at_utc,
run_elapsed_s, mode, out_S, out_Ti_K, out_attitude_input,
alpha_t_deg_resolved, beta_t_deg_resolved, scope, component_id,
component_stl_path, ray_backend_used, CA, CY, CN, Cl, Cm, Cn, CD, CL,
faces, shielded_faces, vtp_path
```

Hypersonic result columns, in order:

```text
solver_version, case_signature, run_started_at_utc, run_finished_at_utc,
run_elapsed_s, out_attitude_input, alpha_t_deg_resolved,
beta_t_deg_resolved, scope, component_id, component_stl_path,
ray_backend_used, CA, CY, CN, Cl, Cm, Cn, CD, CL, faces,
shielded_faces, vtp_path
```

`scope` is `total` or `component`. A multi-STL case emits its total followed by
zero-based component IDs. Total/component coefficients use the same global
reference quantities. `solver_version` records the installed `panel-solvers`
distribution version that generated the artifact. Every total and component
row from one run uses the same value.

## VTP

Cell arrays are aligned with mesh face order:

```text
C_face_stl, area_m2, center_x_stl_m, center_y_stl_m, center_z_stl_m,
shielded, stl_index, Cp_n, theta_deg
```

Common field data is:

```text
alpha_t_deg_resolved, attitude_input_used, beta_t_deg_resolved, case_id,
case_signature, ray_backend_used, solver_version, stl_count, stl_paths_json
```

Hypersonic additionally stores `windward_eq_used` and `leeward_eq_used`. FMF's
resolved `mode`, `out_S`, and `out_Ti_K` values are carried by Summary CSV, not
VTP. `Tw_K` remains an FMF input column.

VTP `solver_version` has exactly the same meaning and source as Summary CSV
`solver_version`. FMF and Hypersonic artifacts generated by the same
`panel-solvers` release therefore record the same value.

## Coefficient and path semantics

`CA`, `CY`, `CN`, `Cl`, `Cm`, `Cn`, `CD`, and `CL` follow
[Numerical conventions](numerical-conventions.md). Disabled artifact paths and
component artifact paths are empty strings in the summary. See
[Outputs](../user-guide/outputs.md) for lifecycle and durability behavior.
