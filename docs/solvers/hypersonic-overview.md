# Hypersonic overview

The Hypersonic domain provides Newtonian-family panel methods with independently
selectable windward and leeward pressure models. It produces pressure-only
normal panel traction for the shared integration engine.

Start with the [Hypersonic input reference](../reference/hypersonic-input.md),
then consult [Pressure models](hypersonic.md) for equations, selector behavior,
limits, and validation plots.
