# FMF overview

The FMF domain models free-molecular-flow panel loads. Its current physical
model is Sentman's diffuse-reflection formulation, including both normal and
tangential local traction.

Start with the [FMF input reference](../reference/fmf-input.md), then consult the
[Sentman model](fmf.md) for equations, assumptions, conventions, and validation
plots.
